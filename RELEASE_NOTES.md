# v0.1.0-alpha.1 candidate

This candidate provides reversible OpenCode setup, strict local configuration, static Codex/Claude Code/AGY adapters, normalized result evidence, explicit-base managed worktrees, MCP `2025-11-25` stdio tools, responsive cancellation/status, process-group cleanup, recursion refusal, and inference-free doctor diagnostics.

It is an alpha candidate, not a published release. Native worker accounts and models remain user-managed. Offline adapter tests do not certify live provider, repository, browser, desktop, Apple, or cross-platform capability. The live OpenCode-to-worker G14 workflow remains a maintainer review gate.

No queue, scheduler, database, provider router, authentication broker, automatic fallback, merge, deployment, or self-update is included.
