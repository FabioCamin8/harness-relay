This does not certify Claude, AGY, browser, desktop, Apple, or cross-platform capability. Maintainer review, hosted final-head CI, merge, tag, publication, and migration remain pending.

No queue, scheduler, database, provider router, authentication broker, automatic fallback, merge, deployment, or self-update is included.
