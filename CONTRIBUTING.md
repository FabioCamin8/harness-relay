# Contributing

Keep changes narrow and preserve the one-master/native-worker boundary. New adapters require a static contract, upstream documentation, installed-help evidence, fake-CLI tests, and explicit live-evidence status.

Run the offline suite from an installed wheel, not only an editable checkout. Tests must use disposable homes and repositories and must not require provider credentials, model inference, private hosts, or maintainer runtime data.

Do not merge, tag, publish, change authentication, or migrate an operational installation as part of an ordinary contribution. Record source SHA, artifact hash, command, environment, result, and limitations for acceptance claims.
